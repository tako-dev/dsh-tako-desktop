# Tako Desktop 用户流程

[English](tako-user-flow.md) | 中文

> **已被取代。** 这份实现前的 spec 作为设计记录保留。DSH Tako 现在以独立桌面应用发布（应用 ID `tech.shiroha.dsh-tako`、数据目录 `~/.dsh-tako`、命令 `dsh-tako`），安装包和更新来自 GitHub Releases，而不是通过官网命令安装到官方 DSH 中的 Tako bundle。下文中“DSH 仍然是官方宿主”“macOS 通过官网命令安装”“不 fork 官方应用”等表述已不再描述当前产品。现行文档：[用户指南](tako/user-guide.zh.md)和[维护者指南](tako/maintainers.zh.md)。

这份 spec 草案定义面向普通用户的目标流程，供开发前评审，不代表全部能力已经实现。DSH 仍然是官方宿主应用；Tako 提供隔离配置、模型提供方、skills 合集和优选插件默认配置。用户不需要理解 profile、bundle 或 MCP。

## 用户主流程

| 阶段 | 用户看到什么、需要做什么 | 系统负责什么 | 失败后的去向 |
| --- | --- | --- | --- |
| 获取与安装 | Windows 下载并打开安装器；macOS 从官网复制一条安装命令。看到下载、配置、检查的进度。 | 自动选择国内/海外 CDN，安装兼容的官方 DSH、Tako bundle 和服务端默认清单，检查后自动启动。 | 显示失败组件并提供重试；浏览器等可选组件失败不阻止进入应用。 |
| 连接 Tako | 一个 key 输入框，主按钮“连接并开始使用”，辅助入口“网页登录”和“稍后配置”。 | 使用 DSH 凭据服务保存 key，验证连接，读取可用模型和额度。网页登录入口须等正式回调接通。 | 区分 key 无效和暂时连不上；允许修改、重试或稍后配置。 |
| 首次工作台 | 推荐的可用 Tako 模型已选好，可以直接输入任务；提供聊天、搜索、生图、语音的示例提示。 | skills 自动启用，默认插件自动配置。仅在任务需要访问用户文件夹时引导选择目录。 | 没有可用模型时显示原因和账户入口；不显示“连接成功即可使用”的误导状态。 |
| 完成任务 | 在同一会话看到进度、回答、图片/音频预览或转写文本；文件可在工作区找到。 | Agent 按任务选择工具，复用 DSH 重试，携带关联 ID，回报后端用量回执。 | 保留已有对话，说明哪个能力失败并提供可执行的恢复方式；不自动切换提供方。 |
| 管理账户 | 设置里的 Tako 页显示套餐、余额、额度及日/周/月用量；充值/续费打开官网。 | 只读取 Tako 后端账本；支持按能力和模型筛选。 | 显示“暂未获取”和更新时间，不把请求失败显示成余额为零。 |
| 扩展和更新 | 插件页默认展示 Tako 优选，可切到完整社区目录；重启后直接回工作台。 | 启动时静默检查兼容组合，有更新再提示；尊重用户的插件选择。 | 保留最后有效清单及可运行组合，并显示修复入口。 |

## 页面与跳转建议

这一节围绕已经确定的行为提出界面布局建议。评审按用户看见页面的顺序进行；profile 挂载、凭据引用、包选择和浏览器通信由技术方案负责。

| 页面 | 主要操作 | 辅助入口与状态 | 下一步去哪 |
| --- | --- | --- | --- |
| 安装进度 | 等待核心安装完成 | 显示下载、校验、配置、验证和启动阶段；只重试失败组件。官网命令和 Windows 安装器共用签名清单与 CDN 回退执行层。 | 自动打开“连接 Tako”；可选组件可以保持待完成。 |
| 连接 Tako | 粘贴 key → 连接并开始使用 | 网页登录作为备用；始终可见“稍后配置”。无需填写接口地址、提供方 ID 或选择 profile。 | 验证可用后进入工作台；稍后配置也进入工作台，Tako 标为未配置。 |
| 工作台 | 在现有 DSH 输入框里写任务 | 显示当前模型和简短 Tako 状态。建议示例只填入输入框，用户发送后才执行。 | 回答和工具结果都留在同一个会话。 |
| 任务结果 | 阅读、预览、播放或打开生成文件 | 搜索显示引用，图片和音频显示预览。共用一套消耗回执；后端尚未结算时显示待结算。 | 继续任务，无需切到独立的生图、语音或搜索应用。 |
| 设置 → Tako | 查看账号和用量 | 更换 key、切换账号、刷新额度、打开官网支付页。按日、周、月查看，可筛选能力和模型。 | 关闭设置后回到刚才的会话。 |
| 插件 → Tako 优选 | 使用已预装能力，或添加选中的插件 | 保留完整社区目录入口；区分下载中、已安装、已启用、失败。默认项安装后直接启用，无需再配置一次。 | 回到工作台即可使用新增能力。 |
| 浏览器标签 | 用户正常浏览；需要时主动把当前标签共享给 Agent | 显示隔离或共享状态。共享后 Agent 操作同一个 Electron WebView，沿用当前页面和登录态；停止共享或关闭标签立即撤销。 | 关闭标签只关闭页面，不悄悄清除持久化浏览数据。 |

## 首个任务走查（评审场景）

评审时以一个新用户的实际任务串起页面：他装好应用、粘贴 key，然后输入“帮我查一下周末露营要准备什么，做一张清单图，再生成一段语音提醒”。这是一条目标体验走查，不是已经跑通的演示。

| 步骤 | 屏幕内容与用户动作 | 可观察的完成条件 |
| --- | --- | --- |
| 1. 安装结束 | 核心组件就绪后自动打开“连接 Tako”；浏览器若没下载完，只显示待完成。 | 用户不用先登录 DeepSeek，不用先访问插件市场，也不用填写接口地址。 |
| 2. 连接账号 | 粘贴 key，点击“连接并开始使用”；原按钮显示检查中，保留“稍后配置”。 | 凭据有效且存在可用模型时进入工作台；额度读取失败独立显示，不误报为 key 无效。 |
| 3. 写第一个任务 | 中间是 DSH 原有对话输入框，已选一个可用的推荐模型；示例可以点入输入框再修改。 | 用户发送任务前无需先选择 skills、配置浏览器或创建项目。没有指定文件夹时，生成物的默认保存位置必须可见且可打开；具体位置待走查确认。 |
| 4. 观察执行 | 当前会话依次展示搜索、生图、语音等实际调用及结果；只有模型决定调用的能力才执行。 | 不跳到三个独立功能页，不要求用户复制图片链接再交给语音功能。搜索引用、清单图和语音播放都留在当前会话。 |
| 5. 查看结果和消耗 | 用户可以打开清单图、播放语音，并展开统一的用量详情；账户页提供聚合查询。 | 有后端回执才展示消耗数值；待结算与零消耗有明确区别。关闭账户页仍回到这次任务。 |
| 6. 继续或退出 | 用户输入“把清单改成亲子出行版”，或关闭应用以后再回来。 | 继续使用同一会话上下文；重新启动后能找到历史结果，保留模型选择，不重复成功完成过的 Tako 配置。 |

浏览器任务另走同一会话中的一条分支：用户提出网页操作任务 → Agent 使用自己的持久化浏览器 → 用户可查看操作状态并停止任务。用户自己打开的 Browser 标签仍属于用户浏览器；“让 Agent 使用当前浏览器”是明确的共享动作，不能仅凭打开标签就改变登录态归属。实时桥接会显示当前标签与登录态已共享，用户停止共享或关闭标签后立即撤销访问。

## 失败与返回路径

失败状态留在发生问题的页面或会话内，并给出下一步动作。下表补充跨页面行为；重试次数和底层退避继续复用 DSH。

| 情况 | 用户看到什么 | 下一步与保留内容 |
| --- | --- | --- |
| key 无效或连接超时 | 分别显示“请修改 key”或“暂时无法连接”。 | 可以修改、重试或稍后配置；不清空尚未提交的任务。 |
| 备用网页登录被取消、超时或回调失败 | 仍在连接页，保留粘贴 key 的主路径。 | 用户可重新登录或改用 key；打开过官网不等于登录成功。 |
| 已连接但模型目录不可用 | 有缓存时显示过期目录；无缓存时显示获取失败。 | 保留模型选择，提供刷新；不自动换提供方，也不把公开推荐表当成可用授权。 |
| 浏览器下载或启动失败 | 对应浏览器能力显示“待完成”或“暂不可用”和重试入口。 | 普通聊天、Tako API 搜索、生图和语音仍可创建会话并使用；不能让浏览器初始化失败阻断所有新任务。 |
| 搜索成功、生图失败 | 保留搜索结果及引用，在生图调用处显示原因。 | 用户在原会话继续；不为了补一张图重新执行整个任务。 |
| 额度不足后前往充值 | 在系统浏览器完成官网操作，应用保留会话与草稿。 | 回来后刷新额度，由用户继续任务；刷新额度本身不重新执行付费请求。 |
| 优选插件安装失败 | 对应卡片显示失败，其他已启用插件继续使用。 | 可重试失败项或回工作台；已下载、已安装、已启用不能合并成一个“完成”状态。 |

连接检查必须区分“已存储凭据”和“已验证可用”。key 验证成功但没有可用模型时，显示模型或额度原因及账号入口；key 验证成功而额度查询失败时，显示“额度暂未获取”，不能宣称 key 无效。超时保留输入并提供“重试/稍后配置”；key 被拒绝时提供“修改 key”。验证不主动发起付费生成请求。

完成过配置后，再次启动回工作台并保留用户模型选择。凭据过期时在工作台显示可修复的 Tako 状态，不遮住已有会话。“稍后配置”是否跨后续启动保留仍是产品待定项；现有访谈只确定它允许本次进入工作台。

## 宿主接入待核对项

发布单元仍是一个顶层 Tako bundle。以下源码事实约束接入设计，不代表允许 fork 官方应用，也不代表缩减已确定的流程。

| 目标体验 | 官方源码发现 | 对设计的影响 |
| --- | --- | --- |
| 首屏配置 Tako 凭据 | 原生 Welcome 在工作台之前运行；[模型引导注册](../packages/client/ui-settings-models/src/client/index.ts)在 Desktop 中关闭自动凭据引导。 | 只改 Web 设置页不能替代原生首启流程。先验证宿主支持的扩展入口，再承诺纯 bundle 能完成。 |
| 不影响已有 DSH 安装 | Desktop 使用固定 desktop profile，并有[单实例控制](../apps/desktop/src/single-instance.ts)；project manager 会把 Tako bundle 注入该 profile。 | 保留数据目录和应用实例检查，并把 Tako bundle 纳入签名 runtime package set；单独命名 CLI profile 仍不能证明 Desktop 可供用户选择。 |
| 市场入口可卸载，Tako 核心必须保留 | [插件管理器](../packages/boot/plugin-manager/src/index.ts)保护管理模块及包含它们的 bundle。 | 可选的 Tako 优选入口与受保护的恢复、管理实现需要区分；核实实际可卸载的范围。 |
| 用户能浏览，Agent 能操作，可主动共享 | 侧边标签是 Electron webview；当前 Desktop 通过标签租约约束的 CDP 桥接向 Host 提供工具。 | 默认隔离。用户主动授权当前会话操作同一标签，撤销或销毁标签时结束桥接。 |
| DSH 与 Tako 按兼容组合升级 | [Desktop 更新器](../apps/desktop/src/update-coordinator.ts)独立于 profile 插件管理宿主版本。 | 先验证支持的更新接入和失败恢复，再承诺兼容性清单可以控制两者。 |

这份流程已经作为实现锚点。连接 Tako、提供方/工具路径、脱敏额度卡、日/周/月用量、按关联 ID 查询消耗回执、用户浏览器持久化、Agent profile 隔离、Tako 优选首屏、安装阶段执行层和一次性 loopback 网页登录回调以及当前标签的主动共享桥接已经有代码与测试。官网清单的真实发布、平台安装器适配和动态签名优选目录仍是验收缺口。下一步按上面的页面跳转做 Desktop 实机走查。

核对基线为官方标签 `dsh-v0.2.1-alpha.2`（2026-10-09），于 2026-10-14 获取远端引用并确认与官方当前提交一致。本次通过 Git 中的官方版本读取源码；本地未提交的 Tako 改动不作为官方已支持的证据。以下描述源码行为；目标流程仍需 Desktop 实机验收。

| 官方现状与证据 | 对目标流程的影响 |

| [插件管理页](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-alpha.2/packages/client/ui-plugin-manager/README.md)已有安装、启用、配置、移除、安装进度和镜像选择。一般手工安装后仍有“Enable now”步骤。 | 复用管理能力，Tako 默认清单要完成“安装并启用”；优选目录排序和完整社区目录入口是需要增加的体验。 |

| [Playwright 浏览器提供方](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-alpha.2/packages/experimental/browser-use-playwright-mcp/README.md)支持 launch/attach，但模式在提供方激活时固定，重载恢复不保证 cookie/页面恢复。 | 独立 Playwright 运行时仍是默认路径；用户选中的实时标签走 Desktop 桥接，不能把安装两个浏览器插件当作验收。 |

| 原生 Welcome 会直接跳到工作台；其[接口](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-alpha.2/apps/desktop/src/welcome-api.ts)明确不保存引导完成状态。 | “稍后配置后，以后启动不再弹出”不是现成保证。记住选择并在工作台保留设置入口是建议方案，仍需产品决定。 |
| 当前 Plugins 页面展示官方条目与已安装 bundle，并接受安装来源；上面的源码核对没有证明它提供完整的社区市场索引。 | 可以复用安装管理能力；完整社区目录由哪个市场插件或服务提供仍待选型。npm 镜像选择器不是社区市场，安装市场插件也不代表优选目录已接通。 |

以上接入点由代码调研和原型验证解决，不让用户选择内部实现。若官方扩展点不足，先记录具体缺口，再评审最小宿主改动；本草案不把修改官方二进制作为默认方案。

## 后端契约核对

本地 Tako 服务源码把用户门户与 OpenAI 兼容 key 网关分开：门户在 `/par/user/*` 下提供 JWT 鉴权的套餐、订阅、用量、日志和模型接口；DSH 插件只有 API key 契约，因此不能假设 `cr_` key 可以调用门户接口，也不能伪造浏览器会话。API-key 账本现在提供日/周/月聚合，DSH 账户页已读取月度字段；回执查询使用新增的 API-key `/apiStats/api/receipt` 只读投影，门户鉴权和能力/模型筛选仍属于接入待核对项，官网登录页已经支持 Desktop 使用的一次性 loopback 回调。缺少接口不能把需求悄悄缩减为一个官网链接。

Tako 服务说明把 Sub2API `usage_logs` 定义为消费权威，窗口、日、周、月和总计都是派生视图。DSH 关联 ID 现在生成稳定的 `dsh-` 加 SHA-256 摘要，并由 Tako 网关写入消费日志的 request id；新增回执接口返回“已结算”“待结算”或“不可用”。API-key 的 `user-quota` 投影还返回钱包折算余额、已用额度、活动套餐标题和到期时间；这些字段只读，不能用于支付。缺失回执不能误显示成零消耗。

## 首次启动

Windows 的目标入口是一键安装器；macOS 一期是官网的一条命令，通过国内/海外 CDN 安装，以后再补 DMG。用户不需要另行安装 Node.js 或 pnpm。`apps/desktop/scripts/tako-install-windows.ps1` 和 `tako-install-macos.sh` 已把清单读取、国内/海外回退、HTTPS 与 SHA-256 校验、官方安装器执行和自动启动串起来；两者都假定 DSH 安装包已经携带 Tako runtime package set，不会在用户 profile 里执行未经确认的 pnpm。bundle 仍提供清单解析、兼容性检查和 download → verify → configure → validate → start 执行层；当前 Desktop project manager 已把 Tako bundle 映射到固定的 `desktop` profile，package-set builder 也会包含它的 tarball。真实官网清单、签名发布和跨平台实机安装验收仍属于发布工作。

首屏进入 Tako 设置页，要求输入 Tako API key；profile 名称留在诊断详情里，不放入普通用户的配置路径。首选路径是粘贴 key；DSH 通过 credential service 保存它，并以 `TAKO_API_KEY` 作为引用。key 不会写入 profile 设置、会话文本、工具结果或诊断信息。校验失败时留在当前页面并显示可执行的错误。用户仍可以进入工作台，此时 Tako 标记为**未配置**，之后在设置里修复。

目标是首次配置只出现一次 Tako 引导，不要求先登录 DeepSeek。网页登录作为已选定的备用路径：系统浏览器打开 Tako 官方登录页，通过一次性 loopback 回调回到 DSH，复用凭据服务。Desktop 和官网回调页已经接通；失败或超时仍保留“粘贴 key”路径。

## 进入工作台

设置完成后，应用打开普通 DSH 工作台，并保持 Tako 的隔离配置。DSH 原有提供方继续可用；只有在这套配置中 Tako 是默认提供方。默认模型从账户实际可用的推荐模型中选择，后续保留用户选择。请求失败时显示 Tako 错误，是否切换到其他提供方由用户决定。

工作台的账号/设置入口显示简短的 Tako 状态：已配置或未配置、上次目录刷新时间和最近一次额度读取。key 缺失或无效不会阻止用户使用会话、文件、插件或其他提供方。

## 模型选择

模型选择器读取实时 Tako 模型目录。公开价格目录 `GET /api/pricing` 可补充展示元数据；带 key 的 `/v1/models` 和账户接口用于确认该 key 的模型权限及额度。公开分组列表不能证明当前账户有使用权限。模型行展示推荐标记和有依据的可用状态；接口未返回的状态标为未知，不从模型名称或营销标签猜测。

离线保留上次成功目录并标记过期。用户可以查看过期条目，但不允许调用上次成功目录中没有的未知模型。首次启动又无法获取目录时显示重试入口，不把内置推荐名单当成授权目录。成功刷新后替换缓存。Tako 请求失败不会静默切换提供方。

## Agent 能力

bundle 安装后自动启用整套 Tako skills，覆盖网页搜索、生图、语音识别、语音生成和只读额度查询；一期不做动态能力发现。何时调用由模型决定，调用直接消耗对应额度，不另加逐次确认。搜索结果保留来源，便于回答中引用。图片和生成的音频在当前会话中可预览，并保存为工作区文件；转写结果直接显示为可读文本。成功生成的媒体提供“打开”或“保存”入口。附件、下载或播放接入尚未打通时，应记为未完成，不能把需求改成只返回结构化数据。

由 Agent loop 调度的文本及工具计费请求都携带 DSH session、turn，以及工具调用的 tool-call 关联 ID；脱离 loop 的独立调用会省略当前不可用的字段。Tako 后端是唯一消耗账本；插件从回执接口读取当前调用状态和账户页聚合。用户询问剩余额度时可调用只读额度工具。插件不另建本地消耗数据库。

## 账号与支付

设置中提供 Tako 账号页，展示当前 key 状态、套餐、余额、额度、模型限制和后端返回的过期时间。API-key 账本已提供日/周/月聚合，账户页显示这些窗口；能力和模型筛选要等后端提供对应字段后再启用。充值和续费在系统浏览器打开 Tako 官方页面；返回应用后支持刷新。同一安装只保留一个当前 Tako 账号，切换时重新认证并清除旧账户的展示缓存。Tako 插件不提供登录、账户修改、模型切换或支付的自动操作工具；这不限制通用浏览器的用途。

## 插件与浏览器

继续使用 DSH Plugins 页面管理插件，并复用现有社区市场能力。当前构建把随 Tako bundle 提供的优选项放在首组，同时保留完整社区目录；release helper 已能校验带签名和版本的远端清单，真实动态清单接入要等发布地址和公钥配置。初次安装项目前由安全的随包默认清单提供，服务器配置接入后不需要改用户流程；安装后整套默认 skills 自动启用。后续清单变化只有标为“必须安装”的项能自动补装，其余新增需确认。只有 Tako 核心不可卸载，市场入口等其他插件可卸载；“必须安装”不能自动等同于“禁止卸载”，用户主动卸载与后续补装的冲突策略需在安装器设计中明确。

可信清单内自动安装；额外权限或构建脚本先展示并让用户确认。签名或版本校验失败停止自动安装，并保留最后有效清单。

用户浏览器是 DSH 工作区内可以关闭的 Browser 标签。用户浏览器与 Agent 浏览器默认各用独立、持久化的 profile，不共享 cookie、存储或登录态；用户明确选择后才共享。共享通过私有 Host IPC 和 CDP 把当前会话接入选中的 Electron 标签；停止共享、关闭标签或 Host 退出都会撤销访问。Agent 浏览器动作自动执行，不另加 Tako 业务限制。用户能看到当前隔离/共享模式及 Agent 操作状态，任务可通过 DSH 的停止操作中断。浏览器运行时优先使用系统 Chrome 或 Chromium；没有时从 Tako CDN 下载固定版本。官方用户标签使用 Electron webview，系统 Chrome 选择适用于隔离的 Agent 运行时。下载失败不回滚 Tako 核心，浏览器标记为待完成并提供重试。

## 更新与恢复

应用启动时静默检查兼容性清单，发现新的 DSH 与 Tako bundle 组合后提示用户。Desktop 更新器在候选版本进入“可用”状态前，先读取 `TAKO_RELEASE_MANIFEST_URL` 指向的 HTTPS 清单，要求 `dshVersion` 与候选 DSH 完全一致，并要求 bundle 版本与当前签名 runtime 中的 Tako 包一致；清单不可用或不匹配时不展示候选，人工检查会看到可修复的错误。未配置清单的开发环境保持官方更新行为。用户确认后按组合更新；失败保留可运行组合及用户数据。安装器的回滚范围、升级中断恢复和官方单实例行为属于发布前验证项。

## 验收条件

- Windows 安装器或 macOS 单条命令结束后自动进入 Tako 设置页；应用内配置 key 无需终端，也不要求 DeepSeek 账号。
- key 校验失败仍能进入工作台，并看到明确的修复入口。
- 模型选择器区分实时、过期、推荐、未知和不可用，不把公开目录当成账户授权。
- 搜索、生图、语音和额度调用出现在当前 turn，带稳定关联 ID 且不泄露 secret。
- Tako 账号页显示后端日/周/月聚合，支付链接到官网；每次工具调用回传关联 ID 和回执状态，已结算时展示 Tako 返回的费用与 token 数据。
- 优选插件清单的校验 helper 已带签名和版本约束；动态远端清单发布前继续使用最后有效清单和随包默认清单。
- 用户与 Agent 浏览器默认隔离且重启保留各自登录态；共享须明确选择，运行时缺失不阻止核心应用启动。
- 第二次启动已配置的 Tako 直接进入工作台，不重复欢迎页；另一套 DSH 安装的配置不受影响。
